# Мастер-промт для ИИ-ассистента: сайт «Дала мемлекеттері AI»

> Этот файл лежит в корне проекта. ИИ-ассистент в VS Code (Copilot, Claude, Cursor и т.п.) должен прочитать его перед любой работой.
> Работаем по этапам (раздел 7): один этап — одна просьба к ИИ, затем проверка в браузере.

## 1. Контекст проекта

Школьный научный проект для республиканского конкурса «Дарын», секция «Дүниежүзілік мәдени мұра. Түркі тілдес халықтар мен қазақ халқының мәдениеті. Әлем халықтарының этнографиясы».
Тема: «Еуразия көшпелі мемлекеттерінің күйреуін ML-моделі арқылы тарихи айнымалылар негізінде болжау».

Сайт — интерактивная визуализация исследования. Жюри — историки и этнографы, поэтому сайт должен быть понятен человеку без знаний программирования, а связь с культурным наследием тюркских народов — заметна на каждой странице.

## 2. Что уже есть (не ломать)

```
ml/train_model.py        — обучает модель, пишет JSON в web/public/data/
web/public/data/*.json   — ЕДИНСТВЕННЫЙ источник данных для сайта
web/src/lib/model.js     — формула риска в браузере (НЕ МЕНЯТЬ логику predictRisk)
web/src/lib/data.jsx     — DataProvider / useData(): загрузка всех JSON
web/src/components/Simulator.jsx, RiskTimeline.jsx — рабочие компоненты, можно улучшать визуально
web/src/App.jsx          — каркас маршрутов (HashRouter)
web/scripts/check-model.mjs — проверка, что JS-модель = Python-модель
```

Структура JSON — смотри README.md, раздел «Python ↔ React байланысы».
Ключевые поля `polities.json`: `id, name_kz, region_kz, founded, collapse_year, lifespan, collapse_type_kz, collapse_desc_kz, static{...}, sources, windows[{start,end,features{...},collapse,risk_oof,risk_fit,top_drivers[],confidence,key_events_kz}]`.

## 3. Жёсткие правила

1. **Никаких выдуманных исторических фактов, цитат, дат и чисел.** Всё историческое содержание берётся из JSON. Если для страницы нужен текст, которого нет в данных (например, цитаты Орхонских надписей, координаты столиц, описания памятников), — создай файл `web/src/content/*.js` с ПУСТЫМИ полями и пометкой `// TODO: заполнить автору по источнику`, не придумывай содержимое.
2. Не менять `model.js` (кроме добавления новых функций) и формат JSON. Если нужно новое поле — сначала скажи, что его надо добавить в `ml/train_model.py`.
3. На графиках истории показывать `risk_oof` (честный прогноз), а не `risk_fit`.
4. Риск всегда подписывать как «тәуекел индексі» (индекс риска), а не «вероятность».
5. Годы до н.э. выводить через `formatYear()` из `model.js`.
6. Без бэкенда, без баз данных, без авторизации. Сайт статический (Vite build → GitHub Pages).
7. Зависимости: только `react-router-dom`, `recharts`, `react-leaflet` + `leaflet` (для карты). Новые библиотеки — только спросив меня.
8. Код простой и с короткими комментариями на казахском или русском: автор — школьник, он должен уметь объяснить код жюри.
9. После каждого этапа: `npm run check-model` и `npm run build` должны проходить без ошибок.

## 4. Языки

Основной и единственный видимый язык интерфейса — **казахский**.
Сделай простой i18n без библиотек: `web/src/i18n/{kz,ru,en}.js` (словари строк интерфейса) + контекст `LangProvider` + хук `useT()`.
Названия факторов уже есть в `model.json` (`label_kz/label_ru/label_en`). Исторические тексты из JSON есть только на казахском — в ru/en показывать их на казахском, это нормально.

## 5. Дизайн

- Настроение: степь, небо, наследие. Фон песочный `#F5EFE3`, основной синий `#1F4E78` (небо, флаг), акцент золотой `#C9A227`, риск — шкала зелёный `#2E7D32` → жёлтый `#F9A825` → оранжевый `#EF6C00` → красный `#C62828`.
- Шрифты: заголовки — `"PT Serif"` или `"Noto Serif"`, текст — `"Noto Sans"` (оба поддерживают казахские буквы ә ғ қ ң ө ұ ү һ і). Подключить через Google Fonts.
- Орнамент: тонкий казахский орнамент (қошқар мүйіз) как SVG-разделитель между разделами — нарисовать простой собственный, не копировать чужие изображения.
- Адаптивность: всё должно работать на телефоне (жюри может открыть с телефона по QR-коду).
- Доступность: контраст текста, подписи к графикам, alt у картинок.

## 6. Страницы

| Маршрут | Название (kz) | Содержание |
|---|---|---|
| `/` | Басты бет | Hero с проверенной цитатой, подзаголовком, тремя числами из `metrics.json`, кнопками «Симулятор» и «Мемлекеттер» и блоком цели исследования. |
| `/timeline` | Уақыт сызығы | Горизонтальная лента −250…1800: каждое государство — полоса из его окон, цвет окна по шкале риска, красная метка в `collapse_year`. Фильтр по региону. Клик → карточка. Под лентой карта с метками столиц из `web/src/content/capitals.js` и SVG-запасной картой. |
| `/states` | Мемлекеттер | Сетка карточек, сортировка по дате, фильтр по региону и типу распада. |
| `/states/:id` | Карточка государства | Шапка: название, годы, срок жизни, тип распада. Значки наследия из `static` (own_script, written_law, succession_system, appanage_system, sedentarization) с подписями. `RiskTimeline`. Таблица окон: период, риск, `top_drivers` (человеческие названия), события, уверенность (H/M/L цветом). Блок «Мәдени мұра» из `content/heritage.js` (TODO). Источники. Кнопка «Симулятордан ашу» → симулятор с пресетом этого государства. |
| `/simulator` | Симулятор | Существующий `Simulator`: слайдеры сгруппированы по `group`, есть полукруглая шкала-спидометр и исторические пресеты через `?preset=ID:index`. |
| `/model` | Модель не дейді | График факторов (горизонтальные точки с интервалами `ci95`, как в `ml/figures/coefficients.png`), карточки гипотез H1–H4 из `hypotheses.json` со статусом-бейджем, сравнение моделей из `metrics.json` (столбики ROC-AUC, базовая модель серым), блок «Модель нені істей алмайды». |
| `/data` | Деректер | Таблица всех окон с поиском и фильтрами и кнопка «CSV жүктеу» с генерацией файла из `polities.json`. |
